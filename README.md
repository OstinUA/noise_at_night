# 🌙 Звуки для сну (Sleep Sounds)

Веб-застосунок для створення розслабляючої атмосфери. Дозволяє комбінувати різноманітні звуки природи, регулювати їх гучність та встановлювати таймер автоматичного вимкнення. Ідеально підходить для сну, медитації або концентрації під час роботи.

## Можливості

- **Мікшер звуків:** Вмикайте та поєднуйте 10 різних атмосферних звуків (Дощ, Гроза, Вітер, Ліс, Океан, Багаття та інші).
- **Індивідуальна та загальна гучність:** Тонке налаштування кожного активного звуку, загальний регулятор і кнопка «Без звуку».
- **Відтворення / пауза:** Зупиняйте та відновлюйте весь мікс одним натисканням, не втрачаючи вибраних звуків.
- **Готові мікси:** Добірка пресетів («Дощова ніч», «Біля багаття», «Узбережжя» тощо) та випадковий мікс.
- **Власні мікси:** Зберігайте улюблені комбінації під власною назвою (до 12 міксів).
- **Таймер сну:** Встановлення часу вручну або кнопками 15 / 30 / 60 / 90 хв. В останні 30 секунд звук плавно затихає, після чого відтворення зупиняється.
- **Автозбереження:** Застосунок запам'ятовує мікс, гучність, мову та стан таймера при перезавантаженні сторінки.
- **Дві мови інтерфейсу:** Українська та англійська, з автоматичним визначенням мови браузера.
- **Керування з клавіатури та системи:** Гарячі клавіші, а також кнопки відтворення на екрані блокування й гарнітурі (Media Session API).
- **Оптимізація:** Аудіофайли завантажуються лише при першому відтворенні (Lazy Loading), що економить трафік.
- **Адаптивний дизайн:** Зручно працює як на ПК, так і на мобільних пристроях.

## Гарячі клавіші

| Клавіша | Дія |
| --- | --- |
| `Пробіл` | Відтворення / пауза міксу |
| `M` | Увімкнути / вимкнути звук |
| `1`–`9`, `0` | Увімкнути / вимкнути відповідний звук |

## Як запустити

1. Завантажте цей репозиторій.
2. Переконайтеся, що папки `sounds/` (з аудіофайлами) та `icons/` (з іконками) знаходяться в корені проєкту.
3. Відкрийте файл `index.html` у будь-якому сучасному браузері.

Збірка та залежності не потрібні. За бажанням застосунок можна запустити через локальний сервер:

```bash
python3 -m http.server 8000
```

## Розгортання

Проєкт є повністю статичним і може бути розміщений на будь-якому хостингу. Для Vercel у репозиторії є `vercel.json`, який додає заголовки безпеки (Content-Security-Policy, `X-Content-Type-Options` тощо) та кешування аудіо й іконок.

## Технології

- **HTML5**
- **CSS3** (Flexbox, Grid, CSS Animations, Custom Properties)
- **Vanilla JavaScript** (ES2022, LocalStorage, Audio API, Media Session API)

## Структура проєкту

```text
├── index.html      # Основна розмітка
├── style.css       # Стилі та анімації
├── script.js       # Логіка застосунку
├── vercel.json     # Заголовки безпеки та кешування для Vercel
├── sounds/         # Аудіофайли (.mp3)
├── icons/          # Іконки (.png)
└── LICENSE         # Ліцензія GNU AGPL v3.0
```
